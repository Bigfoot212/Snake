# Snake Game Refactoring

Tento repozitář obsahuje projekt refaktorizace hry Snake z legacy kódu do podoby, která splňuje standardy čistého kódu (Clean Code).

## Stav: Původní Legacy kód
Toto je výchozí bod projektu. Veškerá logika je v souboru `Program.cs`.
Dále budeme postupovat podle pravidel Clean Code a postupně refaktorovat.
